## 🏆 キーエンス流営業の本質

キーエンスは日本一の平均年収（2,000万円超）を誇る会社。
その営業手法は30年以上変わっていない「再現性のある仕組み」。

### ① 仮説営業
相手に会う前に「この人はこんな悩みがあるはず」という仮説を作っておく。

DM営業に応用すると：
```
送る前に「このお店はインスタ始めたばかりで、投稿の見栄えに困ってるはず」
→ 「投稿、毎回どうやって作ってますか？」から入る
```

### ② バリューセールス（価値の提示）
「商品の説明」をするな。「相手の生活がどう変わるか」を売れ。

```
❌ 「チラシ1枚8,000円で作れます」（商品説明）
✅ 「チラシ1枚あると、お客さんがスマホで写真撮って拡散してくれますよ」（価値の提示）
```

### ③ 数値化思考
感覚で動くな。数字で判断する。

Saraが毎日記録すること：
- 今日送ったDM数
- 返信が来た数（返信率 = 返信数 ÷ 送信数）
- 商談につながった数
- 受注数

→ どのDM文面・どのターゲットが一番返信率が高いかを数字で把握する

### ④ フォローの速度
返信が来たら即対応。「24時間以内」ではなく「できれば1時間以内」。
キーエンスは対応速度が異常に速い。これだけで差がつく。

## 🧠 心理学会話術（必須6法則）

### 1. フット・イン・ザ・ドア（一貫性の法則）

小さなYESを積み重ねると、大きなYESが取りやすくなる。

**DM営業での使い方：**
```
Step 1: 「1枚だけ無料で作りましょうか？」（小さなYES）
Step 2: 「気に入ったら月4枚セットでどうですか？」（大きなYES）
```

最初から月額契約を売ろうとするな。まず「1枚無料」から。

### 2. ザイアンスの法則（単純接触効果）

人は接触回数が増えるほど好意を持つようになる。

**DM営業での使い方：**
```
DM送信前に：
→ 相手の投稿に「いいね」を3回
→ 自然なコメントを1回
→ その後にDM
```

いきなりDMを送るより、先に存在を知ってもらっておく。
これだけで返信率が2倍以上変わる。

### 3. 返報性の法則

何かをもらったら「お返しをしなければ」と思う心理。

**DM営業での使い方：**
```
「1枚無料でお試し制作させてください」
→ 相手は無料でもらった → お礼を言わなければという心理
→ 返信・お礼 → 関係構築 → 有料受注
```

先に価値を渡すと、相手は動きやすくなる。

### 4. 社会的証明

「みんながやっているから正しい」という心理。

**DM営業での使い方：**
```
「飲食店さんのデザインをいくつかやってきまして〜」
「同じエリアの美容室さんにもご利用いただいていて〜」
```

実績・事例を出すと信頼度が上がる。
（実績が少ないうちはポートフォリオ画像を見せる）

### 5. 好意の法則

人は自分のことを好いてくれる人に対して好意を返す。

**DM営業での使い方：**
```
「○○さんのお店、ずっと気になってたんです」
「投稿、毎日楽しみに見てました」
```

本当に見ていることを伝える。嘘はすぐバレる。だから実際に見る。

### 6. 希少性の法則

「限られたもの」は欲しくなる。

**DM営業での使い方：**
```
「今月は実績作りで3社限定で無料お試しをやってます」
「今週末までに決めていただければ〜」
```

ただし使いすぎると信用を失う。自然な文脈で使う。

## 🎯 心理学を使ったDMの理想的な流れ

```
Day 1: 相手の投稿に「いいね」（ザイアンスの法則）
Day 2: 投稿に「いいね」（ザイアンスの法則）
Day 3: 自然なコメント「美味しそうですね！」（好意の法則）
Day 4: DM送信
  → 1文目: 具体的な一言（好意の法則）
  → 本文: 相手の悩みへの共感（共感）
  → オファー: 1枚無料（フット・イン・ザ・ドア＋返報性）
  → 希少性: 「今月3社限定です」（希少性の法則）
```
