## ✅ DM営業の鉄則

### 1文目が全て

DM営業の成功率は「最初の1文」で決まる。
読み手が「自分に関係がある」と感じなければ即閉じられる。

**❌ 悪い1文目**
```
はじめまして！突然のDMすみません🙏
```
→ 全員が使っている。営業感丸出し。即スルーされる。

**✅ 良い1文目（相手の具体的な状況に触れる）**
```
○○さんのパン屋さん、毎日投稿されてるの見てたんですが
最近始めたんですか？
```
→ 「見てた」「自分のこと知ってる」感が出る。返信したくなる。

---

### DM文章の原則

**短く書く**
- スマホで読む → 長いと読まない
- 3〜5行以内が理想
- 「一番伝えたいこと1つだけ」に絞る

**相手の悩みから入る**
```
❌ 「デザイン代行やってます。チラシ作れます」
✅ 「インスタ投稿、毎回作るの大変じゃないですか？」
```

**具体的な一言を必ず入れる**
相手のアカウントを実際に見たという証拠を入れる。
```
「ランチの投稿、毎日されてるの見てました」
「農家さんなんですね、野菜の写真が素朴で好きです」
「最近インスタ始めたばかりですよね？」
```

**オファーはハードルを下げる**
```
❌ 「ご依頼お待ちしております」（ハードル高い）
✅ 「まず1枚だけ無料でお試しできますよ」（ハードル低い）
```

---

### 事前ウォーミングアップ（重要）

いきなりDMを送るより先に：
1. 相手の投稿に「いいね」を2〜3回
2. 自然なコメントを1回
3. そのあとDM

→ 返信率が2倍以上改善する

## ✅ リサーチ精度を上げる方法

### ターゲット選定の原則

**絶対に送ってはいけないアカウント：**
- フォロワー5,000以上（デザイン意識が高い）
- 投稿が統一感ある（プロに頼んでいる可能性）
- チェーン・フランチャイズ（決裁権がない）
- 有名カフェ・映えスポット（デザイン意識が高い）
- フィード全体が統一された色味（すでにブランディング済み）

**送るべきアカウントのサイン：**
- X（Twitter）で「インスタ始めました」と言っている（始めたて確定）
- 投稿がスマホ撮影そのまま（無加工）
- キャプションが絵文字の羅列だけ
- フォロワー100〜1,000人（小規模）
- 投稿数5〜30件（始めたて）
- プロフィールに「〇〇年開業」「新しいお店」などの記載

### 検索の使い方

**Xで最優先検索：**
```
「インスタ始めました」+ 業種
「インスタ開設しました」
「instagram始めました」
```
→ 自分で言っている = 始めたて確定 = 精度最高

**Instagramでの補足検索：**
```
「開業しました」「オープンしました」+ 最近の投稿
「始めました」+ 業種タグ
```

## ✅ コピーライティング基礎（Saraが身につけるべき）

### FAB法則
- **F**eature（特徴）: 「1枚3,000円で作れます」
- **A**dvantage（利点）: 「自分で作る手間が省けます」
- **B**enefit（便益）: 「その時間でお客さんの対応ができます」

→ DM文面は常にBenefitから入れ。特徴や価格から入るな。

### PASONA法則
- **P**roblem: 相手の悩みを言語化する
- **A**ffinity: 共感する
- **S**olution: 解決策を提示
- **O**ffer: 具体的なオファー
- **N**arrow: 限定感
- **A**ction: 行動を促す
