## ❌ やってはいけないHP・LPデザインの特徴

1. **ファーストビューに何も刺さらない** — 3秒以内に離脱。訪問者の60〜70%はファーストビューで帰る
2. **CTAボタンが弱い・埋もれている** — 「お問い合わせはこちら」だけ。押す気にならない
3. **文字が多すぎる** — 読まれない。伝えたいことを1つに絞れ
4. **スマホで見た時がボロボロ** — モバイルトラフィックは全体の75%超
5. **フォームの項目が多すぎる** — 3項目が最もCVR高い。増やすたびに離脱する
6. **ページが重い** — 表示速度3秒超で53%が離脱
7. **デザインが美しいだけで問い合わせが来ない** — 見た目より導線

## ✅ 成果が出るLP・HPの構成（PASONA法則）

LPの構成はこの順番で作る。感覚で並べるな。

```
1. ファーストビュー
   → キャッチコピー（ターゲットの悩みを一言で）
   → サブコピー（解決策のヒント）
   → CTAボタン（今すぐ行動させる）

2. 問題提起（Pain）
   → 「こんなお悩みありませんか？」
   → 読んだ人が「そうそう！」と思う3つの悩み

3. 共感・原因（Affinity）
   → 「それはなぜか？」原因を説明する

4. 解決策の提示（Solution）
   → このサービスがどう解決するか

5. 実績・証拠（Evidence）
   → 事例・before/after・お客様の声

6. オファー（Offer）
   → サービス内容・料金・特典

7. 緊急性（Narrowing）
   → 「今だけ」「先着〇名」

8. CTA（Action）
   → 問い合わせボタン（大きく・目立つ色）
```

## 🎯 CVR（コンバージョン率）を上げる10の法則

### 1. ファーストビューで全て決まる
- 3秒以内に「自分に関係がある」と感じさせる
- キャッチコピーはターゲットの悩みをそのまま言語化する
- ヒーロー画像はサービスの「After（結果）」を見せる

### 2. CTAボタンは目立たせる
- 背景とのコントラストを最大にする
- 「お問い合わせ」より「無料で相談する」「今すぐ試す」
- ページ内に3〜4回配置する（最初・中間・最後）

### 3. フォームは3項目以内
- 名前・メール・メッセージだけでいい
- 電話番号・住所・会社名などは後で聞く
- 入力項目が増えるたびにCVRが下がる

### 4. モバイルファースト
- スマホで見た時のデザインを先に作る
- ボタンは指で押しやすいサイズ（最低44px）
- 文字は最低16px

### 5. 表示速度を最優先
- 画像はWebP形式に変換・圧縮
- アニメーションは最小限
- Googleの「PageSpeed Insights」で90点以上を目指す

### 6. 信頼要素を入れる
- 実績数・制作事例・お客様の声
- 顔写真があると信頼度が大幅に上がる
- 「〇〇件制作」「満足度〇%」などの数字

### 7. 読まれない前提でデザインする
- 見出しだけ読んでも内容がわかるように
- 重要なことは太字・色で強調
- 長文は箇条書きに変換する

### 8. 余白を恐れない
- 詰め込みすぎると読む気が失せる
- 余白はデザインの一部

### 9. 色は3色以内
- CTAボタンのアクセントカラー1色
- それ以外はベース＋テキストカラーのみ

### 10. ABテストで改善し続ける
- 完成後も継続的に改善
- キャッチコピー・CTAボタン・フォームを変えて比較
